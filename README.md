# Markus Wondrak

Domain Architect at a major German bank. My current focus is **agentic coding** —
how AI agents and deterministic workflows fit together, mostly around GitHub's
[Spec-Kit](https://github.com/github/spec-kit). I care less about the prompt and
more about the pipeline around it.

Computer science, nine years in consulting, and a long stretch of Java before that.
